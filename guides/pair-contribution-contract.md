# Pair contribution contract

A pair contribution should record both authors only when both materially contributed to the change.

The primary author owns the branch and pull request. A genuine collaborator can be credited with a `Co-authored-by` trailer using the email associated with that collaborator's GitHub account.

Before merging, verify the commit metadata, the GitHub author mapping, the scope of the change, and the review evidence. The upstream repository does not need to grant either contributor direct push access; fork-based pull requests preserve a clean trust boundary.

This repository uses short-lived branches so each pair contribution remains independently reviewable and reversible.
